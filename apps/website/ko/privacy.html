개인정보처리방침

최종 업데이트: 2026년 6월 10일

Keeply는 로컬 우선 데스크톱 앱입니다 — 버전 관리는 전적으로 사용자의 컴퓨터 또는 사용자가 지정한 위치에서 실행되며, Keeply 자체는 어떤 사용 데이터도 수집하지 않습니다. 파일은 사용자의 기기에 남아 있습니다. 선택적 AI 어시스턴트를 직접 활성화하고 파일을 명시적으로 선택한 경우에만, 해당 내용이 사용자의 컴퓨터에서 사용자가 선택한 AI 서비스 제공업체로 직접 전송됩니다 (아래 「AI 어시스턴트를 사용하기로 선택한 경우」 참조). 이 개인정보처리방침은 당사가 실제로 처리하는 최소한의 데이터, 처리 주체, 그리고 귀하의 권리에 대해 설명합니다.

기본적으로 파일은 사용자의 기기에 남아 있습니다

Keeply는 프로젝트 파일의 버전 기록을 로컬에서 관리합니다. 모든 프로젝트 파일은 사용자의 컴퓨터 또는 NAS에만 저장됩니다. 다음 섹션에서 설명하는 선택적 AI 어시스턴트 (사용자가 직접 활성화해야 하며, 명시적으로 선택한 내용만 전송)를 제외하고, Keeply는 파일 내용을 업로드, 전송, 접근, 읽기 또는 처리하지 않습니다. 당사는 클라우드 스토리지 서버를 운영하지 않으며 어떤 시점에도 사용자의 작업을 열람할 수 없습니다.

Keeply 데스크톱 앱이 수행하는 네트워크 통신은 다음으로 제한됩니다:

  • 라이선스 인증: Keygen.sh와의 통신 (아래 참조)
  • 업데이트 확인: 새 버전 사용 가능 여부 확인
  • AI 어시스턴트 (선택 사항, 기본적으로 꺼짐): AI 서비스를 연결하고 내용을 명시적으로 선택한 경우에만 사용자의 컴퓨터가 선택한 AI 서비스 제공업체에 직접 연결됩니다 (다음 섹션 참조)

위의 AI 어시스턴트 경우 (사용자가 직접 활성화하며, 명시적으로 선택한 내용에만 해당)를 제외하고, 데스크톱 앱은 귀하의 파일 내용이나 파일 메타데이터를 전송하지 않습니다. 또한 Keeply는 현재 어떤 사용 통계도 전송하지 않습니다 (§2.5 참조).

AI 어시스턴트를 사용하기로 선택한 경우

AI 어시스턴트는 기본적으로 꺼져 있습니다. 사용자가 직접 AI 서비스를 연결하고 (본인의 API 키 입력) AI가 볼 수 있는 파일을 명시적으로 선택한 경우에만, 해당 파일의 내용이 사용자의 컴퓨터에서 사용자가 선택한 AI 서비스 제공업체 (예: OpenAI, Anthropic, Google, 또는 본인 컴퓨터에서 실행되는 로컬 모델)로 직접 전송됩니다. 이 과정은 Keeply의 어떤 서버도 거치지 않습니다 — Keeply는 사용자의 내용을 취급하지도, 저장하지도, 볼 수도 없습니다.

로컬 모드 (예: Ollama나 LM Studio로 본인 컴퓨터에서 AI 모델 실행)를 선택하면, 파일 내용은 컴퓨터 밖으로 전혀 나가지 않으며 API 비용도 발생하지 않습니다.

API 키는 컴퓨터 운영 체제의 보안 자격 증명 저장소 (Windows 자격 증명 관리자 / macOS 키체인)에만 저장됩니다. Keeply는 키를 업로드하거나 대신 보관하지 않으며 볼 수도 없습니다. 사용량과 비용은 귀하와 AI 서비스 제공업체 간에 직접 정산되며, Keeply는 비용을 경유하지 않고 어떤 추가 요금도 부과하지 않습니다.

내용이 선택한 AI 서비스 제공업체에 도달한 뒤에는, 그 보관·삭제 및 학습 사용 여부는 해당 제공업체의 약관과 개인정보처리방침에 따릅니다 (예: OpenAI, Anthropic, Google의 개인정보처리방침). 어느 제공업체를 사용할지는 사용자의 결정이며, Keeply는 특정 제공업체를 보증하지 않습니다. 전송하기 전에 해당 제공업체의 정책을 확인하시기 바랍니다.

Keeply의 오류 보고와 통계에는 사용자의 파일 내용이나 AI 대화 내용이 절대 포함되지 않습니다. 또한 AI의 모든 수정은 먼저 제안 형태로 표시되고, 사용자가 확인한 뒤에만 적용되며, 버전 기록에 완전히 기록되어 AI 어시스턴트의 편집으로 표시되고, 한 번의 클릭으로 되돌릴 수 있습니다.

라이선스 인증 시 처리되는 데이터

소프트웨어 라이선스 인증을 위해 Keeply는 Keygen.sh(Keygen LLC, 미국 버지니아주)와 통신합니다. 전송되는 데이터는 다음과 같습니다:

  • 라이선스 키 — 라이선스 유효성 확인
  • 볼트 위치 식별자 — 프로젝트 볼트 고유 ID의 단방향 해시 (원래 식별자 또는 파일 내용으로 역추적 불가)
  • 앱 버전 — 호환성 및 라이선스 범위 확인
  • 볼트 위치 토큰 — 팀 볼트 위치의 해시 식별자(실제 스토리지 경로로 역추적할 수 없음)

사용자의 이름, 이메일 주소 또는 파일 내용은 전송하지 않습니다. Keygen.sh는 SOC 2 Type II 인증을 보유하고 있으며, 국제 데이터 전송에 SCC(표준계약조항)를 사용하고, 서버 로그는 최대 30일, 분석 데이터는 최대 90일간 보유합니다.

자세한 내용은 Keygen.sh 개인정보처리방침을 참조하세요.

법적 근거 (GDPR): 계약 이행의 필요성 (제6조 제1항 (b)).

결제 시 처리되는 데이터

Keeply의 모든 구매는 판매 대행사(Merchant of Record)인 Paddle.com이 처리합니다. 거래 상대방은 Paddle이며, Keeply가 아닙니다. Paddle은 이름, 이메일 주소, 청구 주소, 결제 수단, 위치 및 IP 주소를 수집·처리합니다.

Keeply는 사용자의 신용카드 번호나 전체 결제 정보를 수신, 저장 또는 접근하지 않습니다. Paddle은 주문 이행 및 제품 지원 목적으로만 제한된 구매자 정보(이름, 이메일, 거래 세부 사항)를 당사와 공유할 수 있습니다.

자세한 내용은 Paddle 개인정보처리방침 및 Paddle 구매자 약관을 참조하세요.

법적 근거 (GDPR): 계약 이행의 필요성 (제6조 제1항 (b)) 및 사기 방지를 위한 정당한 이익 (제6조 제1항 (f)).

웹사이트에서 수집되는 데이터

Keeply 마케팅 웹사이트(keeply.work)는 귀하의 선호 언어를 전적으로 브라우저 내에서 감지합니다 — 이 목적을 위해 귀하의 IP 주소를 제3자에게 전송하지 않습니다. 귀하의 언어 선택은 언어 메뉴에서 명시적으로 언어를 선택하거나 언어별 링크(예: keeply.work/ko/)를 여는 경우에만 브라우저의 로컬 스토리지에 저장됩니다.

이메일로 문의하시는 경우, 문의에 응답하기 위해 해당 내용을 보유합니다. 명시적으로 동의하지 않는 한 마케팅 목록에 추가되지 않습니다.

사용 통계

Keeply는 현재 어떤 사용 통계도 수집하지 않으며, 전송하지도 않습니다.

현재 출시된 Keeply 빌드에는 활성화된 사용 통계 보고 기능이 없습니다. 앱 내부에 보고 기능 코드는 존재하지만, 출시 빌드에는 보고 엔드포인트가 설정되어 있지 않아 전체 파이프라인이 비활성 상태입니다 — 설치 출처 카운트를 포함해 어떤 데이터도 전송되지 않습니다. Keeply의 오류 보고와 통계에는 사용자의 파일 내용이나 AI 대화 내용이 절대 포함되지 않습니다.

향후 버전에서 익명 사용 통계를 활성화할 경우, 해당 버전 출시 전에 본 개인정보처리방침을 먼저 업데이트하고, 앱 내에서 명확히 알리며, 해당되는 경우 귀하의 동의를 구할 것입니다.

귀하의 권리

거주 지역에 따라 접근, 정정, 삭제, 제한, 이동, 이의 제기 및 동의 철회의 권리를 보유할 수 있습니다.

EU/EEA 거주자 (GDPR): 위의 모든 권리를 보유하며, 관할 데이터 보호 기관에 불만을 제기할 수도 있습니다.

캘리포니아 거주자 (CCPA/CPRA): 수집되는 개인정보를 알 권리, 삭제를 요청할 권리 및 수신 거부할 권리를 보유합니다. 당사는 개인정보를 판매하지 않습니다.

대만 거주자 (개인자료보호법): 개인 데이터의 접근, 정정 및 삭제 요청 권리를 보유합니다.
